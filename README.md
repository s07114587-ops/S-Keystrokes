# ⚡ Chronos Keystrokes & Performance HUD

> **A sleek, lightweight, and modern overlay HUD built for gamers and creators.**

---

## 📌 About The Project

 Tired of bulky Minecraft mod menus that crash after every update or reset during matches? 
**Chronos Keystrokes & HUD** is a ultra-clean, standalone desktop overlay designed to give you real-time feedback on your keystrokes, CPS, and system frame rates without messing with your game's internal files.

Built using **Python** & **CustomTkinter**, it works effortlessly over **Minecraft (Windows Edition / Java)** and any other game!

---

## ✨ Key Features

* 🎮 **Full Keystroke Visualization:** Real-time visual feedback for `W`, `A`, `S`, `D`, `LMB`, `RMB`, and `SPACE`.
* ⚡ **Live CPS Counter:** High-precision Left-Click Clicks-Per-Second (CPS) tracker.
* 📊 **Integrated FPS Counter:** Keep an eye on your frame rates on the fly.
* 🪟 **Always-On-Top & Transparent:** Stays visible over full-screen/windowed games with adjustable opacity.
* 📐 **Dynamic Scaling:** Preset size modes (*Small*, *Medium*, *Large*) to fit any resolution.
* 🔒 **100% Safe & Open Source:** Zero adware, no bloatware, and no Linkvertise shorteners!

---

## 🛠️ Tech Stack & Dependencies

* **Language:** Python 🐍
* **GUI Framework:** CustomTkinter (CTK)
* **Input Hooking:** Pynput
